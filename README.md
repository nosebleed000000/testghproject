# ГаражПро — заказ-наряды, команда и админ-панель

Рабочий прототип автосервиса в Латвии: канбан-доска заказ-нарядов,
модальные окна создания и просмотра, вход сотрудников, создание аккаунтов
и админ-дашборд. Телефоны — латвийские `+371`, госномера — `AB-1234`,
цены — в евро.

Страницы:

- `index.html` — доска заказ-нарядов;
- `login.html` — вход сотрудников;
- `register.html` — создание аккаунта сотрудника;
- `admin.html` — дашборд администратора.

Исходный согласованный макет сохранён без изменений:
`template/auto-service-board.html`.

## Запуск

Из папки проекта:

```bash
python3 -m http.server 8000
```

Открыть <http://localhost:8000/>.

Можно открыть и `index.html` напрямую через `file://`, но некоторые браузеры
ограничивают `localStorage` для локальных файлов. Через HTTP всё работает
предсказуемо.

Сборка не нужна: обычные HTML, CSS и classic-скрипты без зависимостей.

### Зачем так разбито

Чтобы при следующих доработках не отправлять в контекст весь макет целиком:

- правка цветов/темы — только `styles/tokens.css`;
- правка карточки/бейджа — только `styles/components.css`;
- правка демо-данных — только `scripts/data.js`;
- правка поведения доски — `scripts/board.js`, модалок — `scripts/modals.js`.

`data.js` специально изолирован: при работе над вёрсткой его обычно не нужно
открывать. В `tokens.css` нет селекторов компонентов — только переменные.

## Вход и демо-доступ

Это прототип без бэкенда, пароли не проверяются по-настоящему.

- Вход: `login.html`
  - демо-администратор: `admin@garazapro.lv` / любой пароль от 6 символов
    (кнопка «Подставить» подставит `admin123`);
  - мастера из демо-команды: `igor.kovalev@garazapro.lv`,
    `petr.sazonov@garazapro.lv`, `artem.gusev@garazapro.lv`,
    `marina.litvinova@garazapro.lv`, `roman.dyakov@garazapro.lv`;
  - администратор попадает в `admin.html`, остальные — на доску `index.html`.
- Создание аккаунта: `register.html`
  - демо-код приглашения: `GARAGE-2026`;
  - после создания сотрудник появляется в блоке «Команда» админки;
  - данные хранятся в `garagepro.employees.v1`.
- `admin.html` — дашборд:
  - показатели считаются из тех же 21 заказ-наряда, что и доска;
  - график по этапам, просроченные заказы, последние заказы, команда;
  - поиск по заказам и сотрудникам;
  - на телефоне сайдбар открывается кнопкой-меню.

Кнопка-аватар в шапке доски ведёт в админ-панель. Если открыть
`admin.html` без сессии, показывается демо-администратор; сессия
не-администратора перенаправляет на доску.

## Что работает

- Доска из 8 этапов, карточки со статусами, прогрессом, дедлайнами и ценами.
- Поиск по номеру, автомобилю, клиенту, телефону, госномеру и описанию.
- Фильтр по приоритету и просрочке, счётчик активных фильтров.
- Создание заказ-наряда:
  - проверка обязательных полей и телефона;
  - латвийская маска телефона `+371 26 123 456`;
  - автоматический номер `ЗН-XXXX`;
  - выбор колонки, приоритета, мастера, типа работ, срока и стоимости;
  - новая карточка сразу появляется на доске.
- Просмотр заказ-наряда:
  - клиент, автомобиль, мастер, сроки, стоимость;
  - визуальная шкала этапов;
  - описание работ, метки, прогресс;
  - кнопка перехода на следующий этап.
- Закрытие модалок по `Esc`, клику по фону и кнопке «Закрыть».
- Данные и тема сохраняются в `localStorage` и переживают перезагрузку.
- Ссылки на состояние: `#/new` и `#/order/ЗН-2851`.
- Адаптивность: сайдбар скрывается, доска листается колонками со snap,
  модалки становятся полноэкранными, формы — в одну колонку.
- Вход сотрудников, создание аккаунтов по коду приглашения и выход.
- Админ-дашборд со статистикой, графиком этапов, просрочками, последними
  заказами и списком команды; данные синхронизированы с доской.

## Данные и сброс

Ключи хранилища:

- `garagepro.orders.v2` — заказ-наряды;
- `garagepro.employees.v1` — сотрудники;
- `garagepro.session` — текущая сессия (имя, роль, аватар);
- `garagepro.lastEmail` — e-mail для «Запомнить меня»;
- `garagepro.theme` — выбранная тема.

Ключ версии поднят до `v2` после перехода на латвийские телефоны,
госномера и евро: старые демо-данные `v1` больше не подмешиваются.

Сбросить демо-данные можно из консоли браузера:

```js
GaragePro.store.reset();
GaragePro.employees.reset();
```

или удалить ключ `garagepro.orders.v2` и `garagepro.employees.v1`,
затем перезагрузить страницу.

## Локализация (Латвия)

- Телефоны: код `+371`, 8 цифр, мобильные `2xx xx xxx`, формат
  `+371 26 123 456`; маска и проверка — в `scripts/ui.js`.
- Госномера: формат `AB-1234`, поле принимает до 7 символов,
  автоформатируется и проверяется при сохранении.
- Валюта: евро, формат `lv-LV` (`185 €`); иконка `i-euro` в общем
  `scripts/icons.js`.
- Демо-цены пересчитаны в реалистичные евро, а не просто заменён символ.
- Локация в шапке — «Сервис-центр «Рига»»; юрлицо в демо-данных — `SIA`.

## Токены и темы

Светлая тема — значения в `:root` в `styles/tokens.css`.
Тёмная — блок `:root:is(:has(#theme-toggle:checked),[data-theme="dark"])`.
Переключатель работает на CSS; JS только запоминает выбор и ставит
`data-theme` до первой отрисовки, чтобы не было вспышки светлой темы.

Правило для новых компонентов: не писать цвета напрямую, брать токены
(`--surface`, `--text2`, `--border`, `--blue-soft`, `--shadow-pop` и т.д.).
Если нужен новый оттенок — добавить переменную в оба блока темы.

## Адаптивность

| Ширина | Поведение |
| --- | --- |
| > 1320 | полный десктоп |
| ≤ 1320 | уже поиск |
| ≤ 1280 | у представлений скрываются подписи |
| ≤ 1240 | скрывается часть верхней навигации и подпись даты |
| ≤ 1120 | скрывается сайдбар |
| ≤ 900 | мобильная шапка, поиск отдельной строкой, колонки 320 px; в админке сайдбар становится выдвижным |
| ≤ 640 | телефон: полноэкранные модалки, одна колонка формы, колонка доски на всю ширину; auth-формы в одну колонку |
| ≤ 380 | скрываются название бренда и счётчик |

На телефоне доска — горизонтальный свайп по колонкам; край следующей колонки
виден справа как подсказка.

## Что осталось заготовкой

Верхняя навигация, пункты сайдбара «Клиенты / Склад / Отчёты / Настройки»
и переключатели «Список / Таймлайн» — визуальные заглушки макета.
Бэкенда нет: все изменения и сессия живут в браузере, пароли в демо
не проверяются по-настоящему. Подписи `WIP`, `SLA`, `ОТК` в шапках
колонок — демонстрационные, не пересчитываются.

## Как расширять

**Новый этап.** Добавить объект в `STAGES` в `scripts/data.js` и, при
необходимости, цвет. Колонка и форма создания обновятся автоматически.

**Новое поле заказа.** Добавить поле в форму `index.html`, собрать его в
`collectOrder()` (`scripts/modals.js`), вывести в `cardHtml()` (`board.js`)
и/или `renderView()` (`modals.js`). Старые сохранённые заказы не сломаются,
если обращаться к полю с fallback-значением.

**Новая карточка демо-данных.** Добавить объект в `SEED_ORDERS` с полями
`key`, `stage`, `priority`, `master`, `title`, `desc`, `labels`, `plate`,
`meta`, `client`, `phone`, `foot`, `late`, `done`. Для прогресса —
`progress` и/или `subtasks`.
